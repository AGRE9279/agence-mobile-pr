# Agence mobile Pro

Appli de gestion pour points Mobile Money : caisse, agents, bilan du soir, export Excel, envoi WhatsApp.

- **Utiliser l'appli** : https://agre9279.github.io/agence-mobile-pr/ (après activation de GitHub Pages)
- **Sur un PC sans Internet** : double-cliquer sur `lancer.bat` (Python requis)
- **Mode d'emploi** : `Guide-utilisateurs.pdf` et `LISEZ-MOI.txt`
- **Serveur** : Supabase, projet « agence-mobile-pro »
